# fw-backup

Минималистичный монитор папок в трее Windows. Отслеживает изменения в заданных
папках (источниках) и почти сразу копирует изменённые файлы в соответствующие
папки на другом диске (приёмниках) — «живое зеркало» с корзиной удалённого.

- Один исполняемый файл **~350 КБ**, без внешних зависимостей (CRT вшит).
- Память: ~1.5–7 МБ, процессор: практически ноль (ожидание событий ядра, без опроса).
- Конфиг хранится в реестре (`HKCU\Software\FwBackup`); править его удобнее всего из
  самой программы (иконка в трее → **Настройки…**), но можно и вручную — через
  `reg add`/редактор реестра; после ручных правок нажмите «Перечитать конфиг»
  в меню иконки.

## Как работает

- При старте каждая пара делает **полную сверку** (новые/изменённые файлы копируются,
  исчезнувшие в источнике — уезжают в архив/удаляются на приёмнике);
  при `SkipFullSync=1` стартовая сверка пропускается.
- Дальше события из ядра (`ReadDirectoryChangesW`) группируются с задержкой
  **DebounceMs** (по умолчанию 3 с): файл копируется, только когда программа
  перестала его дописывать.
- **Удаление в источнике → копия переносится в `приёмник\!src_deleted\<полный путь>`**
  (см. «Корзина удалённого» ниже).
- Переименование = копия под новым именем + перенос старой копии в архив.
- Если события переполнили внутренний буфер (массовое копирование), автоматически
  выполняется полная сверка — пропусков не остаётся.
- Файл, занятый другим приложением, обрабатывается повторно 3 раза; при неудаче —
  запись в журнал, на следующем изменении попытка повторится.

## Корзина удалённого (`!src_deleted`)

Всё, что удалено в источнике, не стирается с приёмника, а **перемещается** (внутри
тома — мгновенно) в папку `!src_deleted` в корне приёмника с сохранением полного
относительного пути. «!» стоит не случайно — в сортировке NTFS/Explorer имя,
начинающееся с «!», идёт раньше букв и цифр, поэтому корзина всегда в самом
верху списка:

```
E:\backup\документы\                 ← приёмник (зеркало источника)
E:\backup\документы\!src_deleted\    ← архив удалённого
    └── документы\отчёты\смета.xlsx  ← прежний путь внутри архива
```

- **Восстановить** — перенести файл/папку из `!src_deleted\<путь>` обратно в
  источник на прежнее место; наблюдатель тут же вновь отзеркалирует его в приёмник.
- **Удалить окончательно** — просто стереть файл/папку внутри `!src_deleted`.
- **Посмотреть, что удалялось** — откройте `!src_deleted` в проводнике: там видно
  полное дерево удалённого.
- Если соответствующее место в архиве уже занято (файл удалялся и восстанавливался
  раньше), новый архив получает суффикс ` (2)`, ` (3)` … перед расширением.
- Имя `!src_deleted` **зарезервировано в корне приёмника**. Если папка с таким
  именем окажется в корне ИСТОЧНИКА — в журнале появится предупреждение
  (содержимое такой папки перемешается с архивом удалённого).
- Поведение отключается ключом `ArchiveDeleted=0` (см. таблицу ниже) — тогда
  удаление стирает копию сразу.

## Установка

1. Скопируйте `fw-backup.exe` в постоянное место, например `D:\tools\fw-backup.exe`.
2. Задайте пары папок (источник`|`приёмник), одну строку реестра на пару:

```bat
reg add "HKCU\Software\FwBackup" /v Pairs /t REG_MULTI_SZ /d "D:\my dox\документы|E:\backup\документы" /f
```

Несколько пар — то же самое, значения разделяются символом `\0` (в .reg-файле
или через PowerShell: `[Microsoft.Win32.Registry]::CurrentUser.CreateSubKey("Software\FwBackup").SetValue("Pairs", [string[]]@("C:\src|D:\dst","D:\src2|C:\dst2"), "MultiString")`).

Пути не должны быть вложены друг в друга (бесконечное зеркало отклоняется на старте).
Папка-приёмник будет создана автоматически, если её ещё нет.

3. Запустите `fw-backup.exe`. В трее появится иконка (подсказка — текущее состояние).

## Значения реестра `HKCU\Software\FwBackup`

| Имя            | Тип          | Умолчание | Назначение                                                                 |
|----------------|--------------|-----------|----------------------------------------------------------------------------|
| `Pairs`        | REG_MULTI_SZ | —         | обязательно. Каждая строка: `источник|приёмник`                             |
| `DebounceMs`   | REG_DWORD    | 3000      | мс тишины перед копированием. ≥100                                          |
| `Excludes`     | REG_MULTI_SZ | —         | шаблоны. Без `\` — сверяются с именем файла: `*.tmp`, `~$*`. С `\` — с путём относительно источника: `архив\*` (папка целиком) |
| `ArchiveDeleted` | REG_DWORD  | 1         | `1` — удалённое переносить в `!src_deleted` приёмника; `0` — стирать сразу |
| `KeepOrphans`  | REG_DWORD    | 0         | `1` — не обрабатывать файлы приёмника, исчезнувшие в источнике              |
| `SkipFullSync` | REG_DWORD    | 0         | `1` — не делать полную сверку при старте                                    |
| `LogFile`      | REG_SZ       | —         | путь журнала (UTF-8). Пусто = без журнала                                   |

Пример исключений:

```bat
reg add "HKCU\Software\FwBackup" /v Excludes /t REG_MULTI_SZ /d "*.tmp|~$*|Thumbs.db|архив\*" /f
```

## Окно настроек

Меню иконки → **Настройки…** (или запуск `fw-backup.exe /settings` — окно откроется
сразу при старте). Изменения вступают в силу по кнопке «Сохранить» (наблюдатели
пересоздаются с новыми настройками), «Отмена» закрывает окно без записи.

| Поле | Что писать |
|---|---|
| **Папки для наблюдения** | одна строка на пару: `источник\|приёмник`. Пустой список сохраняется только после подтверждения |
| **Исключения** | один шаблон в строке: `*.tmp`, `~$*`, `Thumbs.db`; шаблон с `\` (например `архив\*`) сверяется с путём относительно источника |
| **Задержка тишины, мс** | DebounceMs, 100–600000 |
| **Журнал** | путь файла журнала (UTF-8); пусто = не вести |
| ☑ **Автозагрузка при входе в Windows** | создаёт/удаляет значение `FwBackup` в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` |
| ☑ **Переносить удалённое в папку !src_deleted** | корзина удалённого (ArchiveDeleted) |
| ☑ **Не удалять на приёмнике то, чего нет в источнике** | защита от зеркальных удалений (KeepOrphans) |
| ☑ **Не делать полную сверку при старте** | SkipFullSync — ничего не копировать при запуске, только реагировать на изменения |

Ручная правка реестра не обязательна — окно настроек пишет ровно те же значения
`HKCU\Software\FwBackup`, что описаны в таблице выше. Если правили реестр
вручную — примените их через меню иконки → «Перечитать конфиг».

## Значок в трее

Значок рисуется программой (готового .ico нет) и показывает состояние:

- **Оранжевый: стрелка вниз + «полка»** — покой, всё скопировано, программа ждёт событий.
- **Красный: три бегущие точки под стрелкой** — идёт копирование/полная сверка.
  Фазы сменяются каждые 400 мс; после окончания копирования анимация ещё немного
  «догорает», и значок мягко возвращается в оранжевый кадр покоя.

Текущее состояние всегда дублируется подсказкой при наведении
(«fw-backup: пар N — активен / пауза / синхронизация»).

Практические заметки:

- Короткая красная вспышка — норма: маленький объём копируется за доли секунды;
  длительность красной фазы пропорциональна объёму копирования.
- Проверять анимацию стоит файлами в **источнике**: файлы, добавленные в приёмник
  извне, программа не копирует обратно (см. `KeepOrphans`) и значком не реагирует.
- Значок сам восстанавливается, если проводник перезапустился и пересоздал панель
  задач (приложение ловит `TaskbarCreated` и ставит значок заново).

## Меню иконки (клик по иконке в трее)

- **Настройки…** — окно параметров (см. выше).
- **Синхронизировать сейчас** — полная сверка всех пар вручную.
- **Пауза / Продолжить** — приостановить копирование (события копятся и отработают после).
- **Перечитать конфиг** — пересоздать наблюдателей с настройками из реестра
  (например, если конфиг правили вручную в обход окна настроек).
- **Выход**.

Второй запуск .exe просто покажет сообщение «уже запущен».

## Сборка

Нужен MinGW-w64 (g++), например WinLibs:

```bat
build.bat
```

или вручную:

```bat
g++ -O2 -s -mwindows fw-backup.cpp -o fw-backup.exe -lshlwapi -static -static-libgcc -static-libstdc++
```

MSVC вариант: `cl /O1 /MD fw-backup.cpp /Fe:fw-backup.exe /link shlwapi.lib`.

## Ограничения

- Владельцем прав на приёмник должен быть текущий пользователь (запись под HKCU).
- Содержимое синхронизируется «как есть» — это копия, а не архив версий (история
  ведётся только для удалённого, в `!src_deleted`).
- Если источник недоступен (съёмный диск отключён), приложение ждёт и подключится
  само; ошибка появится в журнале.
